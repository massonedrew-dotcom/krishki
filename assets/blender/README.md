# assets/blender — procedural lid models

Source scenes for the hero image sequence (task 3b) and the phase-2 GLBs.
Both files are generated by `scripts/blender/build_lid.py`. Do not hand-edit them; change the script and rebuild.

| file | content |
|------|---------|
| `lid-sko.blend` | SKO I-82 lid (`SKO_I82_Lid`) + wikel rubber ring (`SKO_WikelRing`), studio lights, 3 cameras |
| `lid-twist.blend` | Twist-Off 82 lid (`TwistOff82_Lid`) + plastisol compound ring (`TwistOff82_Plastisol`), same studio |

## Rebuild (Blender 5.2.2 LTS, headless, from the project root)

```sh
"D:/Blender/blender.exe" -b -P scripts/blender/build_lid.py -- --type sko   --out assets/blender/lid-sko.blend   --render qa/screens/3d
"D:/Blender/blender.exe" -b -P scripts/blender/build_lid.py -- --type twist --out assets/blender/lid-twist.blend --render qa/screens/3d --color red
```

Options: `--color red|green` (Twist-Off outside colour; both materials `Twist_Outer_Red` / `Twist_Outer_Green` are stored in the file with a fake user, so the variant is a material-slot swap), `--litho path.png` (lithography image on the top face), `--samples N` (default 64), `--res WxH` (default 1200x800), `--transparent` (alpha background instead of ink `#0B0D10`). Leave out `--render` to only build the .blend (about 5 s).
The previews in `qa/screens/3d/` are `<sko|twist-red|twist-green>-<top34|side|under>.png`. The green set was rendered with `--color green --out <temp .blend>`.

## Scene

- Units: metric, 1 unit = 1 m, display in mm. The lid stands on Z = 0, axis = Z. Objects are parented to the empty `LidRoot`.
- Cycles CPU, adaptive sampling, OIDN denoise, AgX "Medium High Contrast".
- Lights: 4 procedural area lights (key softbox, top softbox, rim strip, low fill), all hidden from camera rays. No HDRI is used, so there is nothing to licence.
- World: camera rays see flat ink `#0B0D10`; reflections see a soft grey vertical gradient (Light Path "Is Camera Ray" mix), which makes the metal read on a dark page.
- Cameras: `CAM_Top34` (70 mm, 35° elevation), `CAM_Side_Ortho` (orthographic, for proportions), `CAM_Under34` (the underside render flips `LidRoot` 180° on X and keeps the lights above).

## Geometry

Each lid is a 2D sheet midline profile (r, z) with filleted corners (the fillets act as bevels). The profile is revolved around Z, then thickened with Solidify (0.22 mm, applied). The inner shell gets material slot 1, so the outside and inside coatings are separate slots. Normals are smooth, with sharp edges above 35° and a Weighted Normal modifier (face area, keep sharp). glTF export applies the modifier.

| | SKO I-82 | Twist-Off 82 |
|---|---|---|
| outer Ø | 82.0 mm over the curl | 82.0 mm over the skirt |
| height | 8.6 mm | 11.0 mm (skirt ≈ 10 mm) |
| top | flat panel at z 7.6 mm, raised bead rib r 21–26 mm (+0.55 mm), recessed groove r 31–34 mm (−0.55 mm), raised shoulder r 35–39.4 mm at z 8.5 mm | safety button dome Ø ≈ 17 mm (+0.7 mm over panel) with a groove, recessed centre panel at z 9.4 mm, shoulder r 32–41 mm at z 10.85 mm |
| skirt / edge | slightly flared skirt, curl rolled **inward** (gold outside faces out to the edge), midline radius 0.64 mm | straight skirt, curl rolled **inward**, midline radius 0.72 mm |
| extras | wikel ring: rounded section r 35.9–39.6 mm × 2.0 mm high, under the shoulder | 4 lugs at 45/135/225/315°: only the inner half of the bottom curl is pressed 1.5 mm inward (≈ 10° plateau + 6° falloff), so the outer skirt stays round; plastisol ring r 33.6–40.7 mm, up to 1.2 mm thick, following the underside of the shoulder fillet |
| radial segments | 96 | 128 (lid), 96 (plastisol) |
| triangles | lid 23,808 + ring 3,840 = **27,648** | lid 26,624 + plastisol 3,072 = **29,696** |

Sheet thickness 0.22 mm is the catalog 0.17–0.20 mm tin plus coatings.

## Materials (Principled BSDF)

| material | slot | base (sRGB) | metallic / roughness / coat |
|---|---|---|---|
| `SKO_Outer_GoldLacquer` | SKO 0 | `#D2B872` | 1.0 / 0.25 / 0.6 |
| `SKO_Inner_SilverEnamel` | SKO 1 | `#A4A9AD` | 0.75 / 0.30 / 0.4 |
| `Wikel_Rubber` | ring | `#3A1712` | 0 / 0.8 |
| `Twist_Outer_Red` / `Twist_Outer_Green` | Twist 0 | `#D8352B` / `#1D7A3A` | 0.4 / 0.25 / 0.6 |
| `Twist_Inner_ClearLacquerTin` | Twist 1 | `#D9D2BC` | 1.0 / 0.18 / 0.8 |
| `Plastisol_Compound` | plastisol | `#C9C2B0` | 0 / 0.55 |

The colours are matched by eye to the catalog photos in `assets/reference/`.

**Lithography slot:** the outside materials have an Image Texture node named `Lithography` (UV map `UVMap`, extension EXTEND). Its colour is multiplied over the base colour. By default it holds `litho_placeholder`, a generated plain white 1024² image, so it has no visible effect and contains no artwork or logos. The UV is a planar top projection: `u = 0.5 + x / 84 mm`, `v = 0.5 + y / 84 mm`. The visible top of the lid fills the circle of radius 0.488 around the UV centre. The skirt samples the outer band of the image, so the artwork should carry its edge colour out to the image border. All meshes share this one UV map, which keeps the glTF export simple.
